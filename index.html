⏱

국내·미국 장 상태

★

사용 방법

세 단계면 시작할 수 있습니다

인증키 1개는 동시에 1대의 PC에서 사용할 수 있습니다. 인증키는 현재 운영자 확인 후 무료로 부여됩니다.

회원 가입 · 인증키 신청

회원 가입을 신청하면 운영자가 확인 후 승인합니다. 승인되면 인증키 사용을 신청하고, 인증키를 이메일로 받습니다.

설치하고 인증

설치 파일을 실행하고, 처음 실행 화면에 인증키를 입력한 뒤 이용약관에 동의합니다.

업종·테마 선택

관심 있는 업종이나 테마를 고르고 [추천 종목 분석]을 누르면 10~30초 안에 결과가 나옵니다.

다운로드

설치 파일 받기

설치 파일만으로는 실행되지 않으며, 발급받은 인증키가 필요합니다.

처음 실행할 때 Windows가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행]을 누르세요. 개인 개발 프로그램이라 코드 서명이 없어 나오는 안내입니다.

회원 가입 · 인증키 사용 신청
