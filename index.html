사용 방법

세 단계면 시작할 수 있습니다

인증키 1개는 동시에 1대의 PC에서 사용할 수 있습니다. 인증키는 현재 운영자 확인 후 무료로 부여됩니다.

회원 가입 · 승인

사이트에서 회원 가입을 신청하면 운영자가 확인 후 승인하고, 가입한 이메일로 안내를 보내 드립니다.

설치 · 인증키 신청

사이트에 로그인해 설치 파일을 받아 설치합니다. 프로그램 로그인 창 아래 [인증키 신청]에서 약관에 동의하고 신청하면, 인증키를 가입 이메일로 보내 드립니다.

로그인 · 분석

관심 있는 업종이나 테마를 고르고 [추천 종목 분석]을 누르면 10~30초 안에 결과가 나옵니다.

다운로드

설치 파일 받기

가입 승인된 회원만 로그인한 상태에서 내려받을 수 있습니다. 설치 파일만으로는 실행되지 않으며, 부여받은 인증키가 필요합니다.

처음 실행할 때 Windows가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행]을 누르세요. 개인 개발 프로그램이라 코드 서명이 없어 나오는 안내입니다.

🔑 인증키 받는 방법

  1. 위 다운로드에서 설치 파일을 받아 설치합니다.
  2. Stock Picker를 실행하면 로그인 창이 열립니다. 사이트 회원 이메일 · 비밀번호를 입력합니다.
  3. 로그인 창 아래 [인증키 신청]을 누르고, 인증키 이용약관에 동의한 뒤 신청합니다.
  4. 운영자가 확인 후 가입한 이메일로 인증키를 보내 드립니다.
  5. 로그인 창에 이메일 · 비밀번호 · 인증키를 넣고 로그인하면 시작됩니다.

인증키는 사이트에 표시하지 않고 가입 이메일로만 보내 드립니다. 메일이 보이지 않으면 스팸함을 확인해 주세요.
